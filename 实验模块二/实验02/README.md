## 🚀 快速开始

### 前置条件
1. ✅ WampServer 已启动
2. ✅ ECShop 已安装并运行
3. ✅ Python 虚拟环境已激活
4. ✅ 已安装 selenium 和 webdriver-manager

### 运行实验1（登录用户中心）
```bash
python 实验02_1_登录用户中心.py
```

**测试账号：**
- 用户名：vip
- 密码：vip

### 运行实验2（注册新会员）
```bash
python 实验02_2_注册新会员.py
```

**功能：**
- 自动生成随机用户名
- 填写所有必填字段
- 点击注册按钮
- 自动验证注册是否成功
- 保存截图

## 🔧 故障排查

### 问题1：找不到元素
**解决方案：** 运行辅助工具查找正确的元素定位
```bash
python 查找登录注册元素.py
```

### 问题2：注册失败
**检查项：**
- WampServer 是否启动
- ECShop 是否正常运行
- 网络连接是否正常
- 查看截图文件了解失败原因

### 问题3：ChromeDriver 版本不匹配
**解决方案：** webdriver-manager 会自动下载匹配的版本，首次运行可能需要等待
