## 🚀 快速开始

### 运行主实验
```bash
python 实验03_XPATH定位.py
```

### 运行辅助工具

```bash
python 查找页面元素.py
```

---

## 📝 实验步骤

1. 启动 Chrome 浏览器
2. 打开前台首页
3. 点击登录按钮
4. 点击 ECSHOP 商标返回首页
5. 点击精品推荐区第一个商品
6. 点击高级搜索
7. 输入关键字"100"
8. 点击立即搜索
9. 点击商品（夏新N7或其他）
10. 点击查看购物车
11. 关闭浏览器
