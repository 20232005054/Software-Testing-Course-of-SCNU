## 🔑 关键技术点

### 1. CSS_SELECTOR选择器语法

#### 基本选择器

```python
# 标签选择器
driver.find_element(By.CSS_SELECTOR, "input")
driver.find_element(By.CSS_SELECTOR, "textarea")

# 类选择器
driver.find_element(By.CSS_SELECTOR, ".inputBg")

# ID选择器
driver.find_element(By.CSS_SELECTOR, "#keyword")

# 属性选择器
driver.find_element(By.CSS_SELECTOR, "input[name='user_email']")
driver.find_element(By.CSS_SELECTOR, "input[type='text']")
```

#### 组合选择器

```python
# 多个属性组合
driver.find_element(By.CSS_SELECTOR, "input[type='radio'][name='msg_type'][value='2']")

# 包含匹配
driver.find_element(By.CSS_SELECTOR, "a[href*='message']")

# 开头匹配
driver.find_element(By.CSS_SELECTOR, "input[name^='msg']")

# 结尾匹配
driver.find_element(By.CSS_SELECTOR, "input[name$='email']")
```

### 2. 本实验使用的CSS选择器

| 元素 | CSS选择器 | 说明 |
|------|-----------|------|
| 留言板链接 | `a[href*='message']` | 包含message的链接 |
| 邮箱输入框 | `input[name='user_email']` | name属性定位 |
| 询问单选按钮 | `input[type='radio'][name='msg_type'][value='2']` | 多属性组合定位 |
| 主题输入框 | `input[name='msg_title']` | name属性定位 |
| 留言内容 | `textarea[name='msg_content']` | 标签+name定位 |
| 提交按钮 | `input[type='submit'][value='我要留言']` | type+value定位 |

### 3. 单选按钮操作

```python
# 获取单选按钮
radio_button = driver.find_element(By.CSS_SELECTOR, "input[type='radio'][value='2']")

# 判断是否选中
if radio_button.is_selected():
    print("已选中")
else:
    print("未选中")
    radio_button.click()  # 选中

# 验证选中状态
if radio_button.is_selected():
    print("选中成功")
```

### 4. 中文输入处理

```python
# ❌ 不要用 send_keys 输入中文（会乱码）
element.send_keys("维修")

# ✅ 使用 JavaScript 设置值
driver.execute_script("arguments[0].value = '维修';", element)

# 验证输入
value = element.get_attribute("value")
print(f"当前值: {value}")
```

### 5. 元素操作标准流程

```python
# 1. 定位元素
element = driver.find_element(By.CSS_SELECTOR, "input[name='xxx']")

# 2. 滚动到可见
driver.execute_script("arguments[0].scrollIntoView();", element)
sleep(0.5)

# 3. 清空（如果是输入框）
element.clear()
sleep(0.5)

# 4. 输入内容
# 英文/数字
element.send_keys("vip@163.com")
# 中文
driver.execute_script("arguments[0].value = '中文内容';", element)

# 5. 验证
value = element.get_attribute("value")
print(f"当前值: {value}")
```

## 🐛 问题与解决

### 问题1：邮箱输入框定位失败

**现象：**
```
NoSuchElementException: Unable to locate element: {"method":"css selector","selector":"[name='email']"}
```

**原因：**
- 邮箱字段的name是 `user_email` 而不是 `email`

**解决方案：**
```python
# ❌ 错误
email_input = driver.find_element(By.CSS_SELECTOR, "input[name='email']")

# ✅ 正确
email_input = driver.find_element(By.CSS_SELECTOR, "input[name='user_email']")
```

**经验：**
- 使用辅助脚本查找实际的字段名称
- 不要凭猜测使用字段名

### 问题2：如何确定"询问"按钮的value值

**解决方案：**
1. 使用辅助脚本查找所有单选按钮
2. 发现有5个单选按钮，value分别是0-4
3. 根据顺序判断：留言(0)、投诉(1)、询问(2)、售后(3)、求购(4)
4. 确定"询问"的value是2

**CSS选择器：**
```python
inquiry_radio = driver.find_element(By.CSS_SELECTOR, 
    "input[type='radio'][name='msg_type'][value='2']")
```

### 问题3：单选按钮状态判断

**方法：**
```python
# 使用 is_selected() 方法
if radio_button.is_selected():
    print("已选中")
else:
    print("未选中")
    radio_button.click()
```

**注意：**
- `is_selected()` 返回布尔值
- 只适用于单选按钮和复选框
- 点击后应验证是否选中成功

## 💡 经验总结

### CSS_SELECTOR vs XPATH

| 特性 | CSS_SELECTOR | XPATH |
|------|--------------|-------|
| 速度 | ⚡ 更快 | 较慢 |
| 语法 | 简洁 | 复杂 |
| 功能 | 基本定位 | 功能强大 |
| 向上查找 | ❌ 不支持 | ✅ 支持 |
| 文本定位 | ❌ 不支持 | ✅ 支持 |
| 推荐场景 | 简单定位 | 复杂定位 |

### CSS_SELECTOR优势

1. **性能更好** - 浏览器原生支持，执行速度快
2. **语法简洁** - 类似jQuery选择器，易学易用
3. **可读性强** - 代码更简洁清晰

### CSS_SELECTOR适用场景

✅ **适合使用CSS_SELECTOR：**
- 通过标签、类、ID定位
- 通过属性定位
- 简单的层级关系
- 性能要求高的场景

❌ **不适合使用CSS_SELECTOR：**
- 需要通过文本内容定位
- 需要向上查找父元素
- 复杂的逻辑判断
- 需要使用轴（axis）

### 最佳实践

1. **优先使用唯一属性**
   ```python
   # ✅ 好 - 使用唯一的name
   input[name='user_email']
   
   # ❌ 不好 - 使用通用的class
   .inputBg
   ```

2. **组合多个属性提高准确性**
   ```python
   # ✅ 好 - 多属性组合
   input[type='radio'][name='msg_type'][value='2']
   
   # ❌ 不好 - 单一属性可能不唯一
   input[type='radio']
   ```

3. **使用属性包含匹配**
   ```python
   # ✅ 灵活 - 包含匹配
   a[href*='message']
   
   # ❌ 脆弱 - 完全匹配
   a[href='message.php']
   ```

4. **避免依赖位置**
   ```python
   # ❌ 不好 - 依赖位置
   form > div:nth-child(3) > input
   
   # ✅ 好 - 使用属性
   input[name='msg_title']
   ```

### 调试技巧

1. **在浏览器控制台测试CSS选择器**
   ```javascript

   document.querySelector("input[name='user_email']")

   ```

2. **使用辅助脚本查找元素**
