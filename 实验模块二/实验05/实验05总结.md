### 窗口控制操作

1. **窗口大小控制**
   - `driver.set_window_size(800, 600)` - 设置窗口大小
   - `driver.get_window_size()` - 获取窗口大小
   - `driver.minimize_window()` - 最小化窗口
   - `driver.maximize_window()` - 最大化窗口

2. **窗口位置控制**
   - `driver.set_window_position(60, 60)` - 设置窗口位置
   - `driver.get_window_position()` - 获取窗口位置

### 浏览器导航操作

3. **导航控制**
   - `driver.get(url)` - 访问URL
   - `driver.back()` - 后退
   - `driver.forward()` - 前进

4. **页面信息获取**
   - `driver.title` - 获取页面标题
   - `driver.current_url` - 获取当前URL

## 关键技术点

```python
# 窗口大小
driver.set_window_size(800, 600)
size = driver.get_window_size()
print(f"宽度={size['width']}, 高度={size['height']}")

# 窗口位置
driver.set_window_position(60, 60)
position = driver.get_window_position()
print(f"x={position['x']}, y={position['y']}")

# 窗口状态
driver.minimize_window()  # 最小化
driver.maximize_window()  # 最大化

# 导航
driver.back()     # 后退
driver.forward()  # 前进
driver.get(url)   # 访问URL

# 页面信息
title = driver.title
url = driver.current_url
```
