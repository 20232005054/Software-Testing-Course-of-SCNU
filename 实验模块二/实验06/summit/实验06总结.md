### 核心操作

1. **元素状态判断**
   - `is_enabled()` - 判断元素是否可用
   - `is_selected()` - 判断复选框/单选框是否选中

2. **属性获取**
   - `get_attribute('value')` - 获取输入框的值
   - `element.text` - 获取元素文本内容

3. **元素操作**
   - `clear()` - 清空输入框
   - `send_keys()` - 输入内容
   - `click()` - 点击元素

4. **文本提取**
   - 使用正则表达式从文本中提取数字
   - 从页面源代码中查找信息

## 关键技术点

```python
# 判断按钮是否可用
if button.is_enabled():
    button.click()

# 获取输入框的值
value = input_box.get_attribute("value")

# 判断复选框是否选中
if checkbox.is_selected():
    print("已选中")
else:
    checkbox.click()

# 从文本中提取数字
import re
match = re.search(r'(\d+)', text)
if match:
    number = int(match.group(1))

# 从页面源代码查找
page_source = driver.page_source
match = re.search(r'商品库存[：:]\s*(\d+)', page_source)
```

## 问题与解决

### 问题1：库存数字提取失败

**原因：** 直接获取元素文本只有"商品库存："，没有数字

**解决方案：**
```python
# 获取父元素的完整文本
parent = stock_element.find_element(By.XPATH, "..")
parent_text = parent.text  # "商品库存： 40 台"

# 或从页面源代码中查找
page_source = driver.page_source
match = re.search(r'商品库存[：:]\s*(\d+)', page_source)
```

### 问题2：复选框选中后价格需要更新

**解决方案：**
```python
# 选中复选框后等待价格更新
checkbox.click()
sleep(1)  # 等待JavaScript更新价格
```

## 经验总结

- 元素状态判断很重要，避免操作不可用的元素
- 复选框操作前先判断是否已选中
- 从页面源代码提取信息比DOM更可靠
- 正则表达式是提取数字的好工具
- 操作后要验证结果是否正确
