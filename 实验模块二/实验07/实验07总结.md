## 关键技术点

### Keys类常用按键

```python
from selenium.webdriver.common.keys import Keys

# 特殊键
Keys.ENTER          # 回车
Keys.TAB            # Tab键
Keys.ESCAPE         # Esc键
Keys.BACKSPACE      # 退格
Keys.DELETE         # 删除

# 导航键
Keys.HOME           # Home键（行首）
Keys.END            # End键（行尾）
Keys.ARROW_UP       # 上箭头
Keys.ARROW_DOWN     # 下箭头
Keys.ARROW_LEFT     # 左箭头
Keys.ARROW_RIGHT    # 右箭头

# 功能键
Keys.F1 ~ Keys.F12  # F1-F12

# 组合键
Keys.CONTROL + 'c'  # Ctrl+C（复制）
Keys.CONTROL + 'v'  # Ctrl+V（粘贴）
Keys.CONTROL + 'a'  # Ctrl+A（全选）
Keys.SHIFT + Keys.ARROW_RIGHT  # Shift+右箭头（选中）
```

### 实验中使用的按键

```python
# 1. 回到行首
element.send_keys(Keys.HOME)

# 2. 选中文本（Shift+右箭头×3）
element.send_keys(Keys.SHIFT + Keys.ARROW_RIGHT)
element.send_keys(Keys.SHIFT + Keys.ARROW_RIGHT)
element.send_keys(Keys.SHIFT + Keys.ARROW_RIGHT)

# 3. 复制
element.send_keys(Keys.CONTROL + 'c')

# 4. 粘贴
element.send_keys(Keys.CONTROL + 'v')

# 5. 回车
element.send_keys(Keys.ENTER)
```

### 中文输入处理

```python
# ❌ 不要用send_keys输入中文（会乱码）

# ✅ 使用JavaScript设置值
driver.execute_script("arguments[0].value = '我是';", element)

# ✅ 追加内容
current_value = element.get_attribute('value')

```

## 注意事项

### 1. 文本域回车是换行，不是提交

```python
# 在textarea中按回车 = 换行
textarea.send_keys(Keys.ENTER)  # 换行

# 在input中按回车 = 提交表单
input.send_keys(Keys.ENTER)  # 提交
```

### 2. 组合键的写法

```python
# ✅ 正确 - 使用加号连接
Keys.CONTROL + 'c'
Keys.SHIFT + Keys.ARROW_RIGHT

# ❌ 错误 - 不能用逗号
Keys.CONTROL, 'c'
```

### 3. 选中文本的方法

```python
# 方法1: Shift+箭头键（逐字符选中）
element.send_keys(Keys.SHIFT + Keys.ARROW_RIGHT)

# 方法2: Ctrl+A（全选）
element.send_keys(Keys.CONTROL + 'a')

# 方法3: Home+Shift+End（选中整行）
element.send_keys(Keys.HOME)
element.send_keys(Keys.SHIFT + Keys.END)
```

## 经验总结

- 组合键使用加号连接
- 中文输入仍需使用JavaScript

- 复制粘贴操作需要等待时间
