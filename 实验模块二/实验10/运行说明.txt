实验10 - 切换浏览器窗口 运行说明
========================================

一、运行主实验脚本
----------------------------------------
1. 确保ECShop已启动（Apache + MySQL）
2. 打开命令行，进入实验目录：
   cd "d:\学习资料\大三下\软件测试\实验模块二\实验10"

3. 激活虚拟环境：
   ..\..\venv\Scripts\activate

4. 运行实验脚本：
   python 实验10_切换浏览器窗口.py

二、实验步骤说明
----------------------------------------
1. 打开ECSHOP前台首页
2. 点击注册按钮
3. 点击用户协议链接 → 打开新窗口
4. 保存原始窗口句柄
5. 切换到新窗口（用户协议）
6. 在新窗口中点击配送与支付
7. 点击EC论坛 → 打开第三个窗口
8. 跳过（EC论坛是外部网站）
9. 关闭EC论坛窗口
10. 切换回原始窗口
11. 输入用户名"Jack"
12. 关闭浏览器

三、辅助脚本说明
----------------------------------------
1. 查找首页元素.py - 查找首页的注册按钮和其他元素
2. 查找论坛页面元素.py - 查找EC论坛页面的所有链接

四、关键技术点
----------------------------------------
1. driver.current_window_handle - 获取当前窗口句柄
2. driver.window_handles - 获取所有窗口句柄列表
3. driver.switch_to.window(handle) - 切换到指定窗口
4. driver.close() - 关闭当前窗口

五、注意事项
----------------------------------------
1. 必须先切换到窗口才能操作该窗口的元素
2. 关闭窗口后要立即切换到其他窗口
3. 新窗口打开需要时间，要增加等待
4. 保存原始窗口句柄可以方便地切换回去
5. 新窗口通常是window_handles列表的最后一个

六、特殊说明
----------------------------------------
关于步骤8：
- 原实验要求点击"商业授权"链接
- 但EC论坛链接现在跳转到 www.ecshop.com（外部网站）
- 外部网站没有"商业授权"链接
- 因此跳过了步骤8
- 这不影响窗口切换功能的学习和演示

七、预期输出
----------------------------------------
脚本会打印每个步骤的执行情况，包括：
- 当前窗口句柄
- 所有窗口句柄列表
- 窗口数量
- 当前URL和页面标题
- 每个操作的状态

八、窗口管理示例
----------------------------------------
示例1：切换到最新窗口
  all_handles = driver.window_handles
  driver.switch_to.window(all_handles[-1])

示例2：保存并切换回原窗口
  original = driver.current_window_handle
  # ... 操作 ...
  driver.switch_to.window(original)

示例3：查找特定窗口
  for handle in driver.window_handles:
      driver.switch_to.window(handle)
      if "目标URL" in driver.current_url:
          break
