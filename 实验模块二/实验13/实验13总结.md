## 🔑 核心技术

### 1. 全屏截图

```python

driver.save_screenshot("screenshot.png")

# 使用路径
import os
path = os.path.join("screenshots", "01_登录页面.png")

```

### 2. 元素截图

```python
# 截取特定元素
element = driver.find_element(By.ID, "menu")
element.screenshot("menu.png")
```

### 3. 创建截图目录

```python
import os
if not os.path.exists("screenshots"):
    os.makedirs("screenshots")
```

## 🐛 问题与解决

### 问题1：元素截图失败

**解决方案**：使用try-except，失败时改用全屏截图
```python
try:
    element.screenshot("menu.png")
except:
    driver.save_screenshot("menu.png")
```

### 问题2：步骤8点击登录触发消息框

**原因**：未输入用户名密码就点击登录

**解决**：在步骤9处理消息框，然后在步骤10输入账号

## 💡 最佳实践

### 截图方法对比

| 方法 | 用途 | 优点 | 缺点 |
|------|------|------|------|
| `driver.save_screenshot()` | 全屏 | 简单，包含所有内容 | 文件大 |
| `element.screenshot()` | 元素 | 精确，文件小 | 需元素可见 |

### 截图应用场景

1. **测试证据** - 记录测试执行过程
2. **错误诊断** - 失败时自动截图
3. **报告生成** - 在测试报告中插入截图
4. **视觉对比** - UI自动化测试

### 推荐的截图函数

```python
def take_screenshot(driver, name, element=None):
    """统一的截图方法"""
    os.makedirs("screenshots", exist_ok=True)
    path = os.path.join("screenshots", f"{name}.png")
    
    try:
        if element:
            element.screenshot(path)
        else:
            driver.save_screenshot(path)
        print(f"📸 {path}")
        return path
    except Exception as e:
        print(f"❌ 截屏失败: {e}")
        return None
```
