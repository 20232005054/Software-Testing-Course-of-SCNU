## 🔑 核心技术

### 1. OCR自动识别（推荐）✅

```python
# 安装ddddocr
# pip install ddddocr

import ddddocr

# 截取验证码图片
captcha_img.screenshot("captcha.png")

# 使用OCR识别（show_ad=False隐藏广告信息）
ocr = ddddocr.DdddOcr(show_ad=False)
with open("captcha.png", "rb") as f:
    image_bytes = f.read()
captcha_text = ocr.classification(image_bytes)

# 输入识别结果
captcha_input.send_keys(captcha_text)
```

**识别效果：**
- ✅ ECShop验证码：识别率约 85-95%
- ✅ 简单验证码（数字+字母）：识别率 >90%
- ⚠️ 复杂验证码（干扰线多）：识别率下降

### 2. 万能验证码（仅后台）

```python
# ECShop后台支持万能验证码"0"

```

**适用范围：**
- ✅ 后台管理登录：支持万能验证码"0"
- ❌ 前台用户评论：不支持，需要OCR识别

## 🐛 常见问题

### 问题1：ddddocr未安装

**解决**：
```bash
# 方法1：使用批处理
双击运行：安装OCR库.bat

# 方法2：命令行
pip install ddddocr
```

### 问题2：OCR识别错误

**原因**：
- 验证码复杂度高
- 图片质量差
- 干扰线多

**解决**：
- 多次尝试（刷新验证码）
- 图片预处理（降噪、二值化）
- 使用更好的OCR引擎

### 问题3：前台不支持万能验证码

**解决**：
- 使用OCR识别（推荐）
- 修改ECShop配置支持万能验证码
- 关闭前台验证码功能
