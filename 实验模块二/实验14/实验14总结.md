```python

```

### 2. 查找验证码元素

```python
# 方法1：通过src属性
captcha_img = driver.find_element(By.XPATH, "//img[contains(@src,'captcha')]")

# 方法2：通过ID
captcha_img = driver.find_element(By.ID, "captcha_img")

# 方法3：通过alt属性
captcha_img = driver.find_element(By.XPATH, "//img[contains(@alt,'验证码')]")
```

## 📊 验证码类型

| 类型 | 特点 | 识别难度 | 处理方法 |
|------|------|----------|----------|
| 数字验证码 | 纯数字 | ⭐ | OCR |
| 字母验证码 | 纯字母 | ⭐⭐ | OCR |
| 混合验证码 | 数字+字母 | ⭐⭐⭐ | OCR/打码 |
| 算术验证码 | 简单运算 | ⭐⭐ | 计算+输入 |
| 滑块验证码 | 拖动滑块 | ⭐⭐⭐⭐ | 模拟拖动 |
| 点选验证码 | 点击指定位置 | ⭐⭐⭐⭐ | 图像识别 |

## 🐛 常见问题

### 问题1：找不到验证码图片

**解决**：使用多种定位方式
```python
try:
    captcha_img = driver.find_element(By.XPATH, "//img[contains(@src,'captcha')]")
except:
    captcha_img = driver.find_element(By.ID, "captcha_img")
```

### 问题2：验证码输入后提示错误

**原因**：
- 验证码已过期
- 识别错误
- 区分大小写

**解决**：
- 使用万能验证码
- 刷新验证码
- 检查大小写

## 📚 OCR工具对比

| 工具 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| pytesseract | 开源免费 | 识别率一般 | 简单验证码 |
| ddddocr | 识别率高 | 需要训练 | 中等复杂度 |
| 百度OCR | 识别率高 | 需要付费 | 生产环境 |
| 打码平台 | 识别率最高 | 费用较高 | 复杂验证码 |
