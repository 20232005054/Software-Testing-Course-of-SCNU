### 【说明】
某商店的货品价格（P）都不大于 20 元（且为整数），假设顾客每次付款为 20 元且每次限购一件商品，现有一个软件能在每位顾客购物后给出找零钱的最佳组合（找给顾客货币张数最少）。

## 二、问题描述
“……对于功率大于50马力的机器，并且维修记录不全或已运行10年以上的机器，应给予优先的维修处理……”

- 条件桩：
  C1：功率大于50马力吗？
  C2：维修记录不全吗？
  C3：运行超过10年吗？
- 动作桩：
  A1：进行优先处理
  A2：作其他处理

### 生成判定表

**完整判定表：**

|  | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| C1：功率大于50马力吗？ | Y | Y | Y | Y | N | N | N | N |
| C2：维修记录不全吗？ | Y | Y | N | N | Y | Y | N | N |
| C3：运行超过10年吗？ | Y | N | Y | N | Y | N | Y | N |
| A1：进行优先处理 | √ | √ | √ |  |  |  |  |  |
| A2：作其他处理 |  |  |  | √ | √ | √ | √ | √ |

**分析：**
根据需求"功率大于50马力的机器，并且（维修记录不全 或 已运行10年以上）"
- 规则1、2、3：C1=Y 且 (C2=Y 或 C3=Y) → A1（优先处理）
- 规则4：C1=Y 且 C2=N 且 C3=N → A2（其他处理）
- 规则5、6、7、8：C1=N → A2（其他处理）

### 问题：以上判定表存在冗余，请简化。

**答案：**

**简化后的判定表：**

|  | 1 | 2 | 3 | 4 |
| ---- | ---- | ---- | ---- | ---- |
| C1：功率大于50马力吗？ | Y | Y | Y | N |
| C2：维修记录不全吗？ | Y | N | N | — |
| C3：运行超过10年吗？ | — | Y | N | — |
| A1：进行优先处理 | √ | √ |  |  |
| A2：作其他处理 |  |  | √ | √ |

**简化说明：**
1. **合并规则1和2**：当C1=Y且C2=Y时，无论C3是什么值，都执行A1（用"—"表示无关）
2. **合并规则5、6、7、8**：当C1=N时，无论C2和C3是什么值，都执行A2
3. **简化结果**：从8条规则简化为4条规则
   - 规则1：C1=Y, C2=Y → A1（维修记录不全）
   - 规则2：C1=Y, C2=N, C3=Y → A1（运行超过10年）
   - 规则3：C1=Y, C2=N, C3=N → A2（功率大但条件都不满足）
   - 规则4：C1=N → A2（功率不大于50马力）

## 三、某软件模块需求
某软件的一个模块的需求规格说明书中描述：
1. 年薪制员工：严重过失，扣年终风险金的4%；过失，扣年终风险金的2%。
2. 非年薪制员工：严重过失，扣当月薪资的8%；过失，扣当月薪资的4%。

请绘制出因果图和决策表，并给出相应的测试用例。

**答案：**

### 1. 因果图分析

**原因（输入条件）：**
- C1：是年薪制员工
- C2：是非年薪制员工
- C3：严重过失
- C4：过失

**结果（输出动作）：**
- E1：扣年终风险金的4%
- E2：扣年终风险金的2%
- E3：扣当月薪资的8%
- E4：扣当月薪资的4%

**因果关系：**
- C1 ∧ C3 → E1（年薪制 且 严重过失 → 扣年终风险金4%）
- C1 ∧ C4 → E2（年薪制 且 过失 → 扣年终风险金2%）
- C2 ∧ C3 → E3（非年薪制 且 严重过失 → 扣当月薪资8%）
- C2 ∧ C4 → E4（非年薪制 且 过失 → 扣当月薪资4%）

**约束条件：**
- C1和C2互斥（员工只能是年薪制或非年薪制之一）
- C3和C4互斥（只能是严重过失或过失之一）

**因果图（详细描述）：**

**【重要提示】正确的因果图画法：**

因果图必须包含三层结构：
1. **原因层**（左侧）：输入条件 C1, C2, C3, C4
2. **中间层**（中间）：逻辑节点（AND节点，用∧或三角形表示）
3. **结果层**（右侧）：输出结果 E1, E2, E3, E4

**正确的因果图结构：**

```
原因层              中间层(AND)           结果层
(输入条件)          (逻辑节点)           (输出结果)
─────────          ──────────           ─────────

              ┌──→ [∧] ────────────→ E1 (扣年终风险金4%)
   C1 ────────┤
              │    [∧] ────────────→ E2 (扣年终风险金2%)
              └──→  ↑
                    │
   C2 ────────┬─────┘
              │    
              │    [∧] ────────────→ E3 (扣当月薪资8%)
              └──→  ↑
                    │
   C3 ────────┼─────┴──→ [∧] ──────→ E1
              │          (与C1组合)
              │
              └─────────→ [∧] ──────→ E3
                         (与C2组合)

   C4 ────────┬─────────→ [∧] ──────→ E2
              │          (与C1组合)
              │
              └─────────→ [∧] ──────→ E4
                         (与C2组合)

约束关系（用虚线弧线或虚线框表示）：
   C1 ⊕ C2  ←─── E约束（互斥）
   C3 ⊕ C4  ←─── E约束（互斥）
```

**更清晰的分层表示：**

```
【原因层】        【中间层】              【结果层】

   C1 ─────┐
           ├────→ [AND1] ──────────→ E1
   C3 ─────┤
           │
   C1 ─────┤
           ├────→ [AND2] ──────────→ E2
   C4 ─────┤
           │
   C2 ─────┤
           ├────→ [AND3] ──────────→ E3
   C3 ─────┤
           │
   C2 ─────┤
           └────→ [AND4] ──────────→ E4
   C4 ─────┘

E约束标注：
   C1 ╌╌╌╌╌ C2  (虚线表示互斥)
   C3 ╌╌╌╌╌ C4  (虚线表示互斥)
```

**第一步：标识原因节点和结果节点**

原因节点（输入）：
- C1：是年薪制员工
- C2：是非年薪制员工  
- C3：严重过失
- C4：过失

结果节点（输出）：
- E1：扣年终风险金的4%
- E2：扣年终风险金的2%
- E3：扣当月薪资的8%
- E4：扣当月薪资的4%

**第二步：标识中间节点（逻辑组合）**

中间节点（AND逻辑）：
- AND1 = C1 ∧ C3 → E1（年薪制 且 严重过失）
- AND2 = C1 ∧ C4 → E2（年薪制 且 过失）
- AND3 = C2 ∧ C3 → E3（非年薪制 且 严重过失）
- AND4 = C2 ∧ C4 → E4（非年薪制 且 过失）

**第三步：因果图符号说明**

1. **逻辑符号**：
   - ∧ (AND)：与门，所有输入都为真时输出才为真（用三角形或小圆圈标注）
   - ⊕ (XOR)：异或，互斥约束

2. **约束符号**：
   - E (Exclusive)：互斥约束，用虚线弧线或虚线框连接互斥的原因节点

3. **连接线**：
   - 实线：因果关系
   - 虚线：约束关系

**第四步：完整的因果图关系表**

| 中间节点 | 输入条件 | 逻辑关系 | 输出结果 | 说明 |
|---------|---------|---------|---------|------|
| AND1 | C1, C3 | C1 ∧ C3 | E1 | 年薪制员工发生严重过失 |
| AND2 | C1, C4 | C1 ∧ C4 | E2 | 年薪制员工发生过失 |
| AND3 | C2, C3 | C2 ∧ C3 | E3 | 非年薪制员工发生严重过失 |
| AND4 | C2, C4 | C2 ∧ C4 | E4 | 非年薪制员工发生过失 |

**约束条件说明**：
- **E约束1 (C1, C2)**：员工类型互斥
  - 不能同时是年薪制和非年薪制
  - 必须且只能选择其中一种
  
- **E约束2 (C3, C4)**：过失类型互斥
  - 不能同时是严重过失和普通过失
  - 必须且只能选择其中一种

**因果图的真值分析**：

| C1 | C2 | C3 | C4 | AND1 | AND2 | AND3 | AND4 | E1 | E2 | E3 | E4 | 有效性 |
|----|----|----|----|------|------|------|------|----|----|----|----|----|
| 1  | 0  | 1  | 0  | 1    | 0    | 0    | 0    | 1  | 0  | 0  | 0  | ✓ 有效 |
| 1  | 0  | 0  | 1  | 0    | 1    | 0    | 0    | 0  | 1  | 0  | 0  | ✓ 有效 |
| 0  | 1  | 1  | 0  | 0    | 0    | 1    | 0    | 0  | 0  | 1  | 0  | ✓ 有效 |
| 0  | 1  | 0  | 1  | 0    | 0    | 0    | 1    | 0  | 0  | 0  | 1  | ✓ 有效 |
| 1  | 1  | 1  | 0  | -    | -    | -    | -    | -  | -  | -  | -  | ✗ 违反E约束1 |
| 1  | 0  | 1  | 1  | -    | -    | -    | -    | -  | -  | -  | -  | ✗ 违反E约束2 |

注：1表示真(True)，0表示假(False)，-表示无效组合

**【画图要点总结】**：
1. ✓ 必须有中间层的AND节点（不能直接从原因连到结果）
2. ✓ 每个AND节点接收2个输入，产生1个输出
3. ✓ C1只参与AND1和AND2，C2只参与AND3和AND4
4. ✓ C3只参与AND1和AND3，C4只参与AND2和AND4
5. ✓ E约束用虚线标注在C1-C2之间和C3-C4之间
6. ✗ 不要让所有原因都连到所有结果（这是错误的）
