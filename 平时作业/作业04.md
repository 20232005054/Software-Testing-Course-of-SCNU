```
int DoString(char *string){
    char *argv[100];
    int argc=1;
    while(1) {                                          //1
        while(*string && *string!='-')                  //2,3
            string++;                                   //4
        if(!*string)                                    //5
            break;                                      //6
        argv[argc]=string;
        while(*string && *string!=' ' && *string!='\n' && *string!='\t')  //7,8,9,10
            string++;                                   //11
        argc++;                                         //12
    }
    return 0;                                           //13
}
```

**【问题 1】**

请针对上述 C 程序给出满足 100%DC（判定覆盖）所需的逻辑条件。

**答案：**

判定覆盖（DC）要求每个判定（decision）的真假分支都至少执行一次。程序中共有 4 个判定节点。

| 编号 | 判定语句 | 所在行 | 真分支条件 | 假分支条件 |
|------|---------|--------|-----------|-----------|
| 1 | `while(1)` | 1 | 恒为真，总是进入循环体 | 恒为假，不可达（但结构上存在该分支） |
| 2 | `while(*string && *string!='-')` | 2-3 | `*string != '\0'` 且 `*string != '-'`，例如 string = "abc"（首个字符为 'a'） | `*string == '\0'` 或 `*string == '-'`，例如 string = ""（空串）或 string = "-x"（首字符为 '-'） |
| 3 | `if(!*string)` | 5 | `*string == '\0'`，即字符串已到结尾，例如 string 指向 '\0' | `*string != '\0'`，即字符串未到结尾，例如 string 指向 '-' |
| 4 | `while(*string && *string!=' ' && *string!='\n' && *string!='\t')` | 7-10 | `*string != '\0'` 且不为空格、换行、制表符，例如 string = "-abc"（'-' 后是普通字符） | `*string == '\0'` 或为空格/换行/制表符，例如 string = "- "（'-' 后是空格） |

**推荐测试用例：**

| 用例编号 | 输入 string | 覆盖的判定分支 | 说明 |
|---------|------------|--------------|------|
| TC1 | `""`（空串） | 判定2-假, 判定3-真, break | 字符串为空，直接退出 |
| TC2 | `"-a"` | 判定2-假, 判定3-假, 判定4-真→假 | 含一个短选项，覆盖正常解析流程 |
| TC3 | `"abc"` | 判定2-真→假, 判定3-真, break | 无 '-' 的字符串，跳过字符后结束 |
| TC4 | `"-a -b"` | 判定2-假, 判定3-假, 判定4-真→假→判定2-假, 判定3-假, 判定4-真→假 | 多个选项，覆盖循环 |

```
static void permute_args(int panonopt_start, int panonopt_end, int opt_end, int ncycle)
    int cstart, cyclelen, i, j, nnonopts, nopts, pos;          //1

    nnonopts = panonopt_end - panonopt_start;
    nopts = opt_end - panonopt_end;
    cyclelen = (opt_end - panonopt_start)/ ncycle;

    for(i=0; i < ncycle; i++){                                 //2
        cstart = panonopt_end+i;                                //3
        pos = cstart;                                           //4
        for(j=0; j< cyclelen; j++){                             //4
            if (pos >= panonopt_end)                            //5
                pos -= nnonopts;                                //6
            else
                pos += nopts;                                   //7
        }
    }                                                           //8
}
```

**【问题 1】**

请针对上述 C 程序给出满足 100%DC（判定覆盖）所需的逻辑条件。

**答案：**

判定覆盖（DC）要求每个判定的真假分支都至少执行一次。程序中共有 3 个判定节点。

| 编号 | 判定语句 | 所在行 | 真分支条件 | 假分支条件 |
|------|---------|--------|-----------|-----------|
| 1 | `for(i=0; i < ncycle; i++)`（即 `i < ncycle`） | 2 | `i < ncycle` 成立，即 ncycle > 0 时循环体会执行。例如 ncycle = 3 | `i < ncycle` 不成立，即 ncycle ≤ 0 或循环结束后。例如 ncycle = 0 |
| 2 | `for(j=0; j < cyclelen; j++)`（即 `j < cyclelen`） | 4 | `j < cyclelen` 成立，即 cyclelen > 0 时循环体会执行。例如 cyclelen = 2 | `j < cyclelen` 不成立，即 cyclelen ≤ 0 或循环结束后。例如 cyclelen = 0 |
| 3 | `if (pos >= panonopt_end)` | 5 | `pos >= panonopt_end` 成立，执行 `pos -= nnonopts` | `pos < panonopt_end` 成立，执行 `pos += nopts` |

**推荐测试用例（参数组合）：**

**【问题 3】**

请给出问题 2 中控制流图的线性无关路径。

**答案：**

V(G) = 4，因此有 4 条线性无关路径：

| 路径编号 | 路径序列 | 路径说明 | 覆盖场景 |
|---------|---------|---------|---------|
| Path 1 | R → 1 → 2 → E | 外循环不执行（i < ncycle 为假） | ncycle ≤ 0，函数直接返回 |
| Path 2 | R → 1 → 2 → 3 → 4 → 9 → 2 → E | 外循环执行但内循环不执行（j < cyclelen 为假） | ncycle > 0 但 cyclelen ≤ 0 |
| Path 3 | R → 1 → 2 → 3 → 4 → 5 → 6 → 8 → 4 → 9 → 2 → E | 内循环执行且 if 为真（pos >= panonopt_end） | cyclelen > 0，且当前 pos 在非选项区域 |
| Path 4 | R → 1 → 2 → 3 → 4 → 5 → 7 → 8 → 4 → 9 → 2 → E | 内循环执行且 if 为假（pos < panonopt_end） | cyclelen > 0，且当前 pos 在选项区域 |

**路径覆盖说明：**

- Path 1 覆盖判定 1 的假分支（外循环不执行）
- Path 2 覆盖判定 1 的真分支 + 判定 2 的假分支（外循环执行，内循环不执行）
- Path 3 覆盖判定 2 的真分支 + 判定 3 的真分支（内循环执行，执行 `pos -= nnonopts`）
- Path 4 覆盖判定 2 的真分支 + 判定 3 的假分支（内循环执行，执行 `pos += nopts`）

这 4 条路径覆盖了控制流图中所有有向边，构成一组基路径。
